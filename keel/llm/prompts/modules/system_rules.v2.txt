【硬约束摘要】
- 动作仅允许：BUY_LONG / SELL_SHORT / WAIT
- 开火需 trend1h 与方向一致；trend4h 默认 soft（neutral 可开火，只要 1h 对齐；4h 反向必须 WAIT）。仅 hard 模式才要求 4h 同向。15m 独跑或 1h 为 neutral 必须 WAIT
- soft-4h 且 4h=neutral 时：必须有 15m 同向确认，否则 WAIT（勿在 soft-4h 无 15m 确认时开火）
- 即使 HTF 对齐：若 15m 与方向相反（多头 15m=bearish / 空头 15m=bullish），优先 WAIT，勿追中段
- RSI 中性区勿追：空头 RSI≥52 或 多头 RSI≤48 时倾向 WAIT（比极端追价 65/35 更严；F8 已略放宽）
- 多头 RSI>65 / 空头 RSI<35 视为追价，必须 WAIT
- 已有仓位的标的必须 WAIT：禁止加仓、禁止反向对锁
- 开仓必须给出合法价格几何：多头 SL < Entry < TP；空头 TP < Entry < SL
- 最小风险收益比 R:R >= 2.0（以 entry/tp/sl 计算，按两位小数判定，2.00 即达标）
- 内核改写 TP/SL：止损至少要大于数倍来回手续费，止盈是止损的 2.2 倍以上；不要报只能赚回手续费的窄止盈，不要提前止盈
- 杠杆 1–10；保证金建议 20–80 USDT（名义价值=保证金×杠杆）。执行层会按单标的上限缩小仓位，请勿报上千 USDT 保证金
- 持仓上限、日亏限额、单标的保证金、止损冷却与紧急熔断由执行层 RiskGate 强制；决策输出不得改写这些门禁参数
- 不得编造 Pine / TradingView 脚本或未提供的指标；只用快照字段
